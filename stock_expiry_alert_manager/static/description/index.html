🚀 Up and Running in 10 Minutes

No custom code. No consultants. Just configure and go.

1

Install the Module

Go to Apps → Search "Product Expiry Alert Manager" → Install. All data, crons, and menus are pre-configured out of the box.

2

Enable Lot Tracking on Products

On each product's Inventory tab — Tracking = "By Lots", enable "Use Expiration Dates", set Expiration Time to your shelf life in days.

3

Create a Clearance Location

In Inventory → Configuration → Locations, add an internal location named "Clearance Zone". Near-expiry stock moves here automatically.

4

Configure Alert Settings

Go to Inventory → Expiry Alerts → Settings. Set your threshold days, clearance location, and add email recipients. Done.

5

Receive Stock with Lot Numbers

Validate receipts normally. Enter lot numbers and expiry dates. The system monitors every lot from that moment onwards — fully automatic.

❓ Frequently Asked Questions

Does this work with Odoo Enterprise?

Built for Odoo 19 Community Edition. Uses only CE-compatible models — no Enterprise-only dependencies.

What if a product doesn't have lot tracking?

The module only monitors lots with an expiry date. Products without lot tracking or "Use Expiration Dates" disabled are safely ignored.

Can I customise the alert thresholds?

Yes. Go to Inventory → Expiry Alerts → Settings and set your own GREEN/YELLOW/RED thresholds and exact alert trigger days.

Do I need a separate email server?

No. The module uses Odoo's standard outgoing mail server. Configure SMTP under Settings → Technical → Outgoing Mail Servers once.

Can I stop alerts for a lot I'm already handling?

Yes. Open the lot → Expiry Alerts tab → set "Snooze Alerts Until" to a future date. That lot is skipped by all crons until the date passes.
