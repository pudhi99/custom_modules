🚀 Up & Running in 10 Minutes

1

Install the Module

Apps → Search "Product Expiry Alert Manager" → Install. All crons and menus pre-configured.
2

Enable Lot Tracking

Product → Inventory tab → Tracking = By Lots, enable Use Expiration Dates.
3

Create Clearance Location

Inventory → Locations → New → "Clearance Zone" (internal). Near-expiry stock auto-moves here.
4

Configure Settings

Inventory → Expiry Alerts → Settings. Set thresholds, clearance location and email recipients.
5

Receive Stock — System Takes Over

Validate receipts with lot numbers and expiry dates. 3 crons run daily — fully automatic from day one.

❓ Frequently Asked Questions

Does this work with Odoo Enterprise?

Built for Odoo 19 Community Edition. Uses only CE-compatible models — no Enterprise-only dependencies.

Can I customise the alert thresholds?

Yes. Go to Inventory → Expiry Alerts → Settings and set your own GREEN/YELLOW/RED thresholds and alert trigger days.

Do I need a separate email server?

No. Uses Odoo's standard outgoing mail server. Configure SMTP under Settings → Technical → Outgoing Mail Servers once.

What if a product doesn't have lot tracking?

Only lots with an expiry date are monitored. Products without lot tracking or "Use Expiration Dates" are safely ignored.

Can I stop alerts for a lot I'm handling?

Yes. Open the lot → Expiry Alerts tab → set "Snooze Alerts Until" — that lot is skipped by all crons until the date passes.

Does it block expired lots on internal transfers?

No — only outgoing (customer) deliveries are blocked. Internal clearance transfers for expired stock are explicitly allowed.
