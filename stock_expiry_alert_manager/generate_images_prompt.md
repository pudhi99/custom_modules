## Quick Generation Instructions

1. Open ChatGPT (GPT-4 with DALL·E) or Midjourney
2. Type: "Generate an image with the following specifications:" followed by the prompt
3. If using ChatGPT, add: "Make it look realistic, professional, and suitable for a B2B software marketplace listing. High quality."
4. Download each image at the specified resolution
5. Save them as:
   - `static/description/icon.png` (128×128)
   - `static/description/banner.png` (1280×1493)  
   - `static/description/feature_overview.png` (1200×630)

## Tips for Better Results

- For the icon: Ask for "minimal flat design, single focal point, no gradients"
- For the banner: Ask ChatGPT to generate it in sections if it doesn't fit in one shot
- For the feature overview: Emphasize "professional B2B SaaS style, NOT consumer app style"
- Regenerate 2-3 times and pick the best result
- Use Adobe Express or Canva to add the exact text if the AI-generated text looks wrong
